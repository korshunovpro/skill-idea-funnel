# Инструкция агенту

Этот репозиторий — пакет одного скила. Если пользователь просит его установить, действуй
по этому файлу.

## Где лежит скил

    skills/idea-funnel/
        SKILL.md      метод разбора идеи — сам скил
        PROCESS.md    учёт: статусы, гейты, скоринг, стоп-условия
        templates/    заготовки файлов идеи и воронки

Ставить нужно **папку `skills/idea-funnel/` целиком**. Один `SKILL.md` тоже работает, но
тогда агент ведёт записи по минимальному варианту, а не по процессу.

## Куда ставить

| Среда | Место |
|---|---|
| Codex | `$CODEX_HOME/skills/idea-funnel/` (по умолчанию `~/.codex/skills/`) |
| Claude Code | `~/.claude/skills/idea-funnel/` — личный скил, для всех проектов |
| Claude Code, только этот проект | `.claude/skills/idea-funnel/` |
| Claude в браузере и десктопе | Customize → Skills → Add, zip-архивом; ставит человек, агент этого сделать не может |

Имя папки при установке — `idea-funnel`. Не переименовывай: под этим именем скил
вызывается и на него ссылаются файлы внутри пакета.

## Проверка

Скажи пользователю написать «есть идея» и описать замысел одной фразой. Скил работает,
если разговор начинается с вопросов — откуда идея и чья это боль, — а не с выдачи плана.
