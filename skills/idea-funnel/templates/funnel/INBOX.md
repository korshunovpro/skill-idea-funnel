# Инбокс

Идеи без решения: пока по идее нет ни одного артефакта раскрутки, она живёт здесь
карточкой, а не папкой.

## <Название идеи>

- **Добавлена:** ГГГГ-ММ-ДД
- **Одной фразой:** <что это>
- **Кто носитель боли:** <роль или «не назван»>
- **Что мешает начать раскрутку:** <нет доступа в предметку / ждём решения по другой идее / просто очередь>
