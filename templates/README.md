# templates/ — заготовки файлов

Пустые файлы учёта, описанного в [`PROCESS.md`](../PROCESS.md). Их не нужно читать
подряд: скажите агенту «заведи воронку по `PROCESS.md`» или «заведи папку под идею» — он
разложит нужное сам.

| Куда | Что копировать |
|---|---|
| корень вашей воронки | `funnel/README.md`, `funnel/INBOX.md`, `funnel/RETRO.md`, `funnel/PROJECTS.md`, `idea/DECISIONS.md` |
| папка идеи `<slug>/` | `idea/README.md`, `idea/NOTES.md`, `idea/DECISIONS.md`, `idea/BACKLOG.md` |
| туда же, при переходе в `план` | `idea/PLAN.md` |
| туда же или в рабочую область | `idea/STATUS.md` |

`idea/NOTES.md` устроен по этапам метода: пустой раздел — это ворота, которые ещё не
пройдены. Заполняется по ходу разговора, а не в конце.

Шаблоны — предложение, а не обязательство. Лишние разделы удаляйте, свои добавляйте:
состав того, что должно быть записано, задан в `SKILL.md` («Что записывать»), а форма ваша.
